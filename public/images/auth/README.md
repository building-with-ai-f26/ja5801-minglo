# Google sign in button assets

Unmodified Android + Web, PNG @2x, Show text Yes, Shape Square, Light/Dark
assets from Google's official pre-approved branding bundle, retrieved November 21,
2026. Original size 360 × 80; rendered at 180 × 40 inside a minimum 44px target.
Text and the Google logo are part of the supplied asset. The button has an
accessible text label; the decorative image has empty alternative text.

Source: https://developers.google.com/static/identity/images/signin-assets.zip
Guidelines: https://developers.google.com/identity/branding-guidelines
