# Public Sans

Unmodified WOFF2 files from the [official USWDS Public Sans repository](https://github.com/uswds/public-sans/tree/develop/fonts/webfonts), bundled for consistent headlines and branding without runtime third-party font requests.

- `PublicSans-SemiBold.woff2` → `public-sans-semibold.woff2`, weight 600.
- `PublicSans-Bold.woff2` → `public-sans-bold.woff2`, weight 700.

Source branch: `develop`, downloaded November 11, 2026. See the included `OFL.txt` and `LICENSE.md` for the upstream licenses and notices. Body text retains the platform sans fallback; other scripts continue to fall back as needed.
